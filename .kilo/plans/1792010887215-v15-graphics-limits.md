# V15 Graphics Limitations Plan (100% code read)

## Limiting Factor

`v8Lod()` (line 161) maps `settings.quality` → 0/1/2, gating all visual detail:

| Feature | Low (0) | Balanced (1) | High (2) |
|---|---|---|---|
| Particles | 96 | 256 | 512 |
| Particle budget | 0.5x | 1.0x | 1.6x |
| Screen atlas update | 1 Hz | 2 Hz | 4 Hz |
| Arch shadow pass | Off | On | On |
| Cables/animation | Off | On | On |

- `V9_DEFAULTS` line 594: NO `quality` key — relies on base game default

- WebGL2 context line 20: `getContext("webgl2",{alpha:!1,antialias:!1,depth:!0,powerPreference:"high-performance",preserveDrawingBuffer:!1})` — antialias is FALSE (no MSAA)

## Root Cause

1. **`'ultra'` tier does not exist.** Line 910 references `'ultra'` only as a temporary hack in `v9Resize()`. `v8Lod()` maps anything that isn't `'low'` or `'high'` → 1 (balanced). There is no 4th tier.

2. **`settings.quality` defaults to "balanced" (not undefined)** — base game line 20 sets `settings={quality:"balanced",...}`. So `v8Lod()` returns 1 by default, capping at balanced quality.

3. **Quality tier ceiling is 'high' (512 particles, 2560px resolution cap)** — no option beyond high exists.

4. **No MSAA** — WebGL2 context created with `antialias:false`.

5. **V15 `installV15Hooks()` does not initialize `quality`** — it only adds `strobeLevel`. If user clears localStorage, `quality` stays at base default "balanced".
