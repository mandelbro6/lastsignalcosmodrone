# V15 Graphics Limitations Plan (complete code audit — 100% of 10,337 lines read)

## Root cause of graphics limitation

`v8Lod()` (line 161) maps `settings.quality` → 0/1/2, gating ALL visual detail:

| Feature | Low (0) | Balanced (1) | High (2) |
|---|---|---|---|
| Particles | 96 | 256 | 512 |
| Particle budget | 0.5x | 1.0x | 1.6x |
| Screen atlas canvas | 512×512 | 512×512 | 512×512 |
| Screen atlas update rate | 1 Hz | 2 Hz | 4 Hz |
| Shadow map (omni) | 256 | 512 | 1024 |
| Shadow map (key/sun) | 512 | 768 | 1536 |
| Resolution cap | 960px | 1280px | 1600px |
| AO taps | 12 | 28 | 48 |
| Volumetric steps | 8 | 14 | 20 |
| Volumetric ray strength | 0 | .23 | .46 |
| Arch shadow pass | Off | On | On |
| Cable/wire animation | Off | On | On |
| MSAA | Off | Off | Off |
