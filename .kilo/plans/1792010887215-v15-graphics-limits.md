# V15 Graphics Limitations Plan

## Limiting Factor

`v8Lod()` (line 161) maps `settings.quality` → 0/1/2, gating all visual detail:

| Feature | Low | Balanced | High |
|---|---|---|---|
| Particles | 96 | 256 | 512 |
| Particle budget | 0.5x | 1.0x | 1.6x |
| Screen atlas update | 1 Hz | 2 Hz | 4 Hz |
| Arch shadow pass | Off | On | On |
| Cables/animation | Off | On | On |
| Cylinder/rib/truss segments | lod-gated | lod-gated | lod-gated |

`'ultra'` is referenced at line 910 but never implemented as a real tier. `settings.quality` is not in V9 defaults, so it's undefined unless set via localStorage (undefined → balanced).

## Decisions

| Decision | Choice |
|---|---|
| Quality tiers | Add 'ultra' as 4th tier (LOD=3) |
| WebGL context flags | Verify during implementation (minified block) |
| Scope | V15 hooks + recommended base code changes |

## Tasks

### 1. Add 'ultra' quality tier
- `v8Lod()` (line 161): add `settings.quality === 'ultra' ? 3 : 1` fallback
- `installV15Hooks()`: inject `<option value="ultra">Ultra</option>` into `#quality` select (HTML line 16)
- `installV15Hooks()`: default `settings.quality = 'ultra'` if not set

### 2. Ultra detail levels (V8 base code)
- `v8BuildArchitecture()` (lines 193-346): ultra-only cylinder segments, truss bays, ribs count, megastructure towers
- `v8BuildDynamics()`/`v8DrawDynamics()` (lines 362-382): ultra cable animation counts

### 3. Particle system ultra
- `v8PartInit()` (line ~444): ultra count 1024
- `v8PartTick()` (line ~454): ultra budget 2.4x

### 4. Screen atlas ultra
- `v8ScreenInit()` (lines 397-399): 1024x1024 canvas, 256x256 tiles; update `v8Tile()` UVs
- `v8ScreenTick()` (line 429): update round-robin stride for larger tiles

### 5. Resolution cap (V9 base code)
- `v9Resize()` (lines 906-913): remove `settings.quality = 'ultra'` hack; add uncapped/3840px mode

### 6. WebGL context flags (verify during implementation)
- Check `new Renderer($("world"))` context creation for `antialias`, `powerPreference`
- Add if missing

## Verify During Implementation (base game — minified)

| Item | Why |
|---|---|
| `settings` object declaration | Confirm `quality` default isn't already set |
| `wireControls()` definition | Confirm quality select is wired to `settings.quality` |
| WebGL context creation flags | Determine if antialias/powerPreference need adding |

## Validation
- `settings.quality` = 'ultra' by default; `v8Lod()` returns 3 for 'ultra'
- Particle count = 1024 on 'ultra'; screen atlas = 1024x1024
- 'ultra' option visible in quality `<select>`
- No regression: 'low'/'balanced'/'high' behave as before
